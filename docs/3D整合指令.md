# 3D 舞台整合 — 給 Code 任務的操作步驟

## 一、先把檔案放進 repo
把這個壓縮包裡的 `3d/` 資料夾整個拖進 repo 根目錄（和 `index.html`、`bank/` 同層），`CLAUDE.md` 用壓縮包裡的新版覆蓋。
放好後 repo 會多出：
```
3d/README.md  3d/core.js  3d/chars.js  3d/habitats.js  3d/scenes.js  3d/game.js
3d/build.py   3d/stubtest.js  3d/habitat-3d.html
```
Commit 一次（訊息例：`Add 3D stage prototype`）。推上去之後 `https://yvonneyen86-wq.github.io/habitat-battle/3d/habitat-3d.html` 就能直接在白板上開啟獨立展示頁。

## 二、在 Code 任務貼這段（第一步：先看實機再整合）
```
請先讀 CLAUDE.md 和 3d/README.md。
3d/ 是 Three.js 3D 舞台原型，還沒接進 index.html。
第一步只做校正：我會貼白板上開 3d/habitat-3d.html 的截圖，請依截圖調整
鏡頭角度、角色大小、對話泡泡名牌位置與四個場景的地標比例，
每次只改 3d/ 裡的檔案，改完跑 node 3d/stubtest.js，重新 python3 3d/build.py，
然後推上 main。用中文回我，列出改了什麼。
```

## 三、視覺確認後，貼這段（第二步：整合）
```
請依 3d/README.md「整合進 index.html 的建議做法」把 3D 舞台接進 index.html：
1. 加 Three.js r128 CDN 與一個 🎮 3D Stage 開關（預設關閉，狀態存 localStorage），
   開啟時隱藏 2D canvas、顯示 #stage；THREE 載入失敗自動退回 2D。
2. 用 S.players 取代示範 ROSTER，做 CHAR_MAP 把正式角色 id 對到 CHAR_BUILDERS 的 16 個 key。
3. 在 markCorrect / resolveRound / summonBoss / bossAttack / bossDefeated / castSpell / revealVote
   裡呼叫對應的 3D 動作（只在 3D 開啟時）。
4. 學生端不變，仍是 2D。
5. 保持單檔 index.html，所有學生／白板看得到的文字維持英文。
做完請跑 CLAUDE.md 的測試步驟，再用 📱 Student view 跑一題 Learning Time 與一回合 battle，
確認 2D 關閉與 3D 開啟兩種模式都正常，再推上 main。用中文回我。
```

## 四、之後要改 3D 畫面時
一律「一張截圖＋一句要改什麼」，例如：
```
附圖是 Dino 場景。火山再大一點、往後退，角色往前一些，名牌字再大。只改 3d/scenes.js 和 3d/game.js。
```
