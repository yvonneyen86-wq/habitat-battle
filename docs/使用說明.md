# Habitat Battle 棲息地對戰：使用說明

## 一、正式網址（已上線）
**https://yvonneyen86-wq.github.io/habitat-battle/**

- 老師電腦用 Chrome 打開這個網址，就是中控＋投影畫面；學生平板掃畫面上的 QR code 加入，不需要帳號。
- 檔案放在 GitHub repository **yvonneyen86-wq/habitat-battle**（GitHub Pages，從 main 分支發佈）。
- 要更新遊戲：在 Claude 對話裡說要改什麼 → 拿到新的 index.html → 到 repository 的 index.html 頁面按鉛筆或 **Upload files** 覆蓋同名檔案 → Commit，1–2 分鐘後網站自動更新，網址與 QR code 不變。

## 二、課前設定（⚙️ Setup）
- **場景**：Jungle Safari／Dino Valley／Space Quest／Hero Town
- **組數**：2–4 組，可改組名
- **對戰時間**：10／15／20／25／30 分鐘（預設 20）
- **Learning Time 題庫**：一行一題，`|` 後面是答案（只有老師看得到）
- **📚 Textbook（教材題庫）**：上方 **📚 Textbook** 按鈕（Setup 裡也有 **Choose units**）。選級數 OD1–OD5 → 勾選正在教的單元 → **✓ Use these units**（取代目前題庫）或 **➕ Add to my questions**（加在現有題庫後面）。每個單元有 10 題 Learning Time（單字意思、拼字、文法、課文內容、開放題）和約 10 題 Battle（涵蓋所有題型），全部依課本內容編寫。上方按鈕會顯示目前載入的級數與單元，例如 `📚 OD3 U1,2`。
  - OD1 U17、OD5 U7／U9／U10 標示 **partial**：雲端資料夾缺少部分頁面，題目依課本前面的 Scope and Sequence 字表與現有頁面編寫，使用前請過目。
  - 題庫原始文字檔在 `題庫原始檔` 資料夾（OD1.txt–OD5.txt），要修改題目可直接編輯，再貼進 Setup。
- **Battle 題庫**：一行一題，開頭的字母代表題型，用 `|` 分隔：

| 題型 | 格式 | 學生怎麼答 |
|---|---|---|
| **T** 打字 | `T \| 題目 \| 範例句（可省略）` | 平板打完整句，下方有 ⚡ 句子能量條 |
| **S** 口說 | `S \| 題目` | 舉手口說 |
| **B** 句子拼圖 | `B \| 正確的句子` | 平板上點單字卡排順序，系統自動判斷 |
| **F** 錯誤偵探 | `F \| 錯句 \| 正確句（多個答案用 / 分隔）` | 打出正確句，和答案相同就自動通過 |
| **W** 指定字造句 | `W \| 目標字 \| 提示（可省略）` | 打字，系統檢查有沒有用到目標字 |
| **P** 看圖說話 | `P \| 🦁🌧️🏠 \| 提示` | 口說（改成 **PT** 就是打字） |
| **C** 二選一說理由 | `C \| 問題 \| 選項A \| 選項B` | 平板先選，再口說 because… |
| **Z** 搶答 | `Z \| 題目` | 平板按「I KNOW!」，最快 3 人取得回答權 |

## 三、課堂流程

### ① Learning Time（課堂前段）
- 學生掃 QR → 輸入英文名字 → 選組別 → 選角色。
- 學生答對：按 **✓ +2 🪙**；表現好：按 **⭐ Great job**（+1 🪙＋1 個角色道具，集滿 3 個會充好角色技能）。
- 也可按 **❓ Question Card** 在投影畫面出全班題，或按 **🪙 +1 Everyone** 全班加幣。
- 學生在平板的 **Supply Shop** 自己花錢：

| 商品 | 價格 | 效果 |
|---|---|---|
| 🏠 升級棲息地 | 3 🪙／5 🪙 | 血量 ❤️ 10 → 15 → 20 |
| ⚔️ 攻擊裝備 | 2 🪙 | 攻擊造成 3 傷害（沒有裝備時是 1） |
| 🛡️ 防禦裝備 | 2 🪙 | 蓋牆 +3 護盾（沒有裝備時是 +1） |
| 🍖 補給品 | 2 🪙 | 修復 +4 ❤️（沒有裝備時是 +1） |

### ② Battle（最後 20 分鐘）
按上方 **⚔️ Start Battle**，畫面會切換成戰場並開始倒數。每一回合：
1. 按 **❓ Next Question**（或在輸入框自己出題，按 🎤 口說／⌨️ 打字／🔔 搶答）。
2. **批改分三級**，每位學生列上有三個按鈕：
   - **✓ Good**：一般行動。
   - **⭐ Great**：攻擊或防禦效果 ×2。
   - **🌟 Amazing**：×2 並穿透護盾，投影畫面播放「CRITICAL HIT!」。
   - 打字題會列在右側 **Sentences**，每句有 ⚡ 能量（大寫、標點、5 字、8 字、連接詞）；**✓ Approve N complete** 一次通過格式正確的句子，能量滿格自動給 ⭐。
   - 句子拼圖、錯誤偵探會自動判斷，第一次就對給 ⭐。
3. 答對的學生在平板選行動：**⚔️ 攻擊**、**🛡️ 蓋牆**、**❤️ 修復**。
4. 可選 **🛡️ Defense**：被攻擊的組別收到一題防守題，答對的人按 **🛡️ Block**，可擋下一次攻擊。
5. 按 **⚔️ Resolve** 播放攻防動畫。
6. 時間到會跳出提醒，打完這回合按 **🏁 End Battle** 看結果（名次、MVP）。

**特殊玩法（Battle Control 內的按鈕）：**
- **🔥 連續答對**：連續 3 回合答對，棲息地冒火，攻擊 +1。
- **⚡ 角色技能**：學生集滿 3 個徽章後，在平板按技能即可立即發動，不需老師確認。
- **👹 Summon Boss**：召喚大魔王（依場景不同），全班一起攻擊它，每回合它會反擊 3 位學生。打倒後全班 +2 🏆 +2 🪙，適合當結尾。
- **🗳️ Vote best sentence**：從老師通過的好句子抽 4 句（不顯示名字）投影出來，學生在平板投票，按 **Show results** 公布。贏的學生 +3 🪙 +3 🏆。

## 四、對戰規則（保護機制）
- **只能選「組別」攻擊**，系統會打該組血量最多的棲息地，不會集中攻擊同一個孩子。
- **沒有淘汰**：棲息地 0 ❤️ 會睡著 💤 一回合，下一回合自動以半血重建；睡著的學生答對也能立刻重建。
- **落後補給**：每回合血量最低的組別全員 +2 🛡️（📦 Supply drop）。
- **🏆 計分**：造成的傷害、蓋牆／修復各 +1、打倒對方棲息地 +3。

## 五、角色技能（3 個道具充 1 次，對戰時使用）
| 角色類別 | 技能 |
|---|---|
| Animal Friends 🐾 | Team Cheer：全組 +2 ❤️ |
| Dino Squad 🦴 | Dino Dash：下次攻擊傷害 ×2 |
| Space Crew 🌙 | Warp Strike：下次攻擊穿透護盾 |
| Town Heroes 🏅 | Golden Shield：立即 +5 🛡️ |

## 六、其他
- 沒有平板的學生：按 **+ Add player** 手動加入；對戰時按 ✓ Correct 會跳出視窗，由老師代選行動。
- **🌱 Back to Learning**：結束對戰回到學習階段（保留金幣與棲息地）。
- **Setup → Reset game**：保留學生，金幣、棲息地、裝備歸零。**New class**：產生新的 QR code，給下一個班級用。
- 老師端重新整理頁面，進度會保留，學生平板會自動重新連線。
- 上方 **✨** 可關閉動畫（電腦較舊時使用）。

## 學生自選外型（2025-10 新增）
- 學生掃 QR 加入時，除了名字、隊伍、角色，還會看到 **Design your look**：膚色、髮型（9 種）、髮色、衣服顏色、圖案（條紋／圓點／星星／號碼）。按 🎲 Surprise me 可隨機。
- 選好的外型會出現在學生平板左上角、老師端的學生列表，以及之後的 3D 舞台（新竹的學生、太空組的太空人都會用這個外型，所以同一隊的太空人也分得出誰是誰）。
- 加入後想改：點平板左上角自己的頭像（有 ✏️），改好按 Save。
- 外型會記在學生的平板裡，下次用同一台平板加入會自動帶入；老師手動加入的學生會依名字自動配一個固定外型。

## 3D 舞台（2025-10 新增）
- 老師端右上角 **🎮 3D** 可開關（預設關閉）。開啟後投影區變成 3D 島嶼：每隊一個基地、每位學生一棟家、角色依世界變成叢林動物／恐龍／太空人／新竹學生，答對、攻擊、升級、Boss 都會在 3D 裡演出。
- 關閉就回到原本的 2D 畫面；網路載不到 3D 程式時會自動留在 2D 並提示。學生平板不受影響，仍是 2D。
- 學生列表每位學生左邊的 **🎤**：鏡頭貼近那位學生（指定回答時用）。投影區左下：**👥 隊伍**＝整隊排好面對鏡頭；**🏝️ Island**＝回到全景；**🏕️ Bases**＝幫各隊選基地。
- 白板上也可以直接點某個角色聚光、用手指拖曳轉鏡頭、雙指縮放。
- **平板迷你 3D**：⚙️ Setup →「Student tablets」選「🎮 Mini 3D (own home)」→ 每台平板上方的家會變成 3D（自己的家、自己的角色、答對會跳、被打會 ><、升級會擴建）。平板太慢時會自動換回 2D 圖片。預設是 2D 圖片。

### Learning Time（右側面板）
| 按鈕 | 功能 |
|---|---|
| +1 🪙 all（隊伍卡） | 該隊每人 +1 金幣 |
| + Add player | 老師手動新增一位學生（沒平板也能玩） |
| ✓ +2 🪙 | 這位學生答對：+2 金幣 |
| ⭐ Great job | 答得特別好：+1 金幣 **再加一個職業道具**（集滿 3 個可用大招） |
| −🪙 | 扣 1 金幣（誤按時用） |
| ✕ | 移除這位學生（要按兩次確認） |

學生在平板用金幣買：升級棲息地（更多 ❤️）、攻擊／防禦／補給道具。

### Battle（右側 Battle Control）
| 按鈕 | 功能 |
|---|---|
| ❓ Next Question | 出下一題（從 Setup 的戰鬥題庫輪流出） |
| 自訂題目框 + 🎤 ⌨️ 🔔 | 臨時出一題：🎤 口說、⌨️ 打字、🔔 搶答 |
| ✓ Good / ⭐ Great / 🌟 Amazing（學生列） | 評分。Good 正常攻擊；Great 傷害 ×2；Amazing ×2 且穿牆。評完學生平板才會出現行動選單 |
| ↺ | 取消評分 |
| 🎁 | 另外給 +1 金幣和一個職業道具 |
| ✓ Approve n complete | 一鍵把所有完整句子評為 Good（句子寫得好的自動 Great） |
| Show model answer | 顯示／隱藏參考答案 |
| 🛡️ Defense | 防禦挑戰：被攻擊的隊伍再答一題，答對的學生按 🛡️ Block 可擋一次攻擊 |
| ⚔️ Resolve (已選/已評分) | **結算**：執行所有人選好的修理、蓋牆、攻擊，Boss 反擊，進入下一回合 |
| 👹 Summon Boss | 召喚 Boss（血量依人數），學生可選擇打 Boss；打敗全班 +2 🏆 +2 🪙 |
| 🗳️ Vote best sentence | 把這回合通過的句子拿出來讓全班投票，🏅 Show results 揭曉，最佳 +3 🪙 +3 🏆 |
| 學生列的「…」 | 老師代替學生選行動（攻擊某隊／打 Boss／蓋牆／修理） |
