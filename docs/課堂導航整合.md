# Habitat Battle × 課堂導航（活動卡規格 v1）

Habitat Battle 已照「課堂導航・活動卡規格 v1」接好橋。單獨打開網址時一切照舊；放進課堂導航時名單、題目由導航送進來，作答與判分會回報。

## 兩個畫面
| 網址 | 用途 |
|---|---|
| `index.html?screen=board` | 白板（主機）。收到 `cr:init` 後：跳過 QR／New class，名單＝`init.students`，題目＝`init.questions.lines`，`CR.ready(遊戲代碼)` |
| `index.html?screen=tablet` | 平板。收到 `cr:init` 後：用 `init.join` 連白板，自動以 `init.me` 的身分加入（不用打名字、不用選隊伍角色；外型仍可在平板上改，記在這台平板的 `habitat-av-<學生id>`） |
| 沒有 `?screen=` | 單獨模式，原本流程（QR 加入、Class list、精靈）都在 |

## 名單與題目
- `init.students[]` → 每位學生一個玩家，`crId = students[].id`；隊伍自動平均分、角色隨機、金幣每堂歸零（manifest `points:false`，不吃 `init.points`）。
- 同一個 `session.id` 重新載入白板會接回剛才的進度（存在 `localStorage` 的 `habitat-cr-<session.id>`）；不同 session 一律全新。
- `init.questions.lines`：一行一題、`|` 分欄。若有 `# learn` / `# battle` 標記就照標記分；沒有的話，第一欄是 `T S B F W P PT C Z` 的算戰鬥題，其餘算 Learning Time 題。回報時 `question` = 該行在 `lines` 裡的索引（從 0 算）；老師臨時出的題沒有索引。

## 回報（`CR.event`）
| kind | 誰送 | 何時 |
|---|---|---|
| `start` | 白板 | 第一次按 Question Card 或 Start Battle |
| `answer` | 平板 | 送出句子／拼句子按 Check／選 A B／按搶答鈴。`correct` 一律 `null`（由老師或白板判） |
| `grade` | 白板 | 老師按 ✓/⭐/🌟（`level` good/great/amazing，`points` 0）；Learning Time 按 ✓ +2 🪙（good，points 2）、⭐ Great job（great，points 1）；程式自動判對（拼句子、改錯句）`auto:true` |
| `points` | 白板 | +1 Everyone／隊伍 +1／−🪙／買升級或道具（負數）／打敗 Boss +2／最佳句子 +3 |
| `finish` | 白板 | 收到 `cr:end` 時送（若還在戰鬥會先結算）。`results` 依 🏆 排名，`points` = 剩餘金幣 |

## 檔案
- 橋：`index.html` 最前面的 `<script>`（規格原文，不要改）。
- 遊戲端整合：`index.html` 裡 `crHostSetup / crFinish / crEvent / crTabletAnswer`，以及 `CR.start(...)` 開機。
- `cr-manifest.json`：`questions:"bank"`、`teacherGrades:true`、`points:false`、`minutes:20`。

## 題目格式補充
- 試車場／導航送來的行可以多一欄單元代碼：`T|U5|What do bears eat?|Bears eat fish and berries.`，遊戲會自動略過 `U5` 那一欄。
- 拼句子題可以把字塊用 ` / ` 列出：`B|U5|lives / in / a / tree / A monkey|A monkey lives in a tree`，字塊就照 ` / ` 切；沒有字塊就照單字打散。
- 如果送來的全部是戰鬥題（T/C/B…），Learning Time 的 Question Card 會用同一批題目的題幹（拼句子題變成 "Say this sentence: …"），回報時仍對到原本那一行。

### 從課堂導航直接進某個 Learning Time
課堂導航登記了五張 Habitat 卡,網址都是 `index.html` 加 `?mode=`:`words` 🔤、`reading` 📖、`grammar` 🧩、`speak` 💬、`battle` ⚔️(或不帶 = 原本的操作台)。
白板收到 `cr:init` 後,會把送來的那一課(`## Un` 加 `# words / # reading / # grammar / # speak-write`)當成 Learning Time 的單元,並照 `mode` 直接開那個活動,不用再按 📚 Textbook。平板跟著白板走,不用改。單獨打開網址時 `mode` 沒有作用。
### 文法公式卡(`# grammar` 的 R 行)
```
# grammar
R | Simple Past · Regular Verbs | verb + -ed → listened · traveled | didn't + verb → didn't watch | many years ago · long ago
R | Verb changes | watch → watched | play → played
G | People listened to the news on the radio.
```
`R | 標題 | 一行 | 一行 …`,想放幾行放幾行(肯定、否定、問句、時間詞都可以)。白板進 🧩 Grammar 時,公式卡先出現在句子上面(照課本 Learn Grammar 框);孩子平板排句子時上方有一行小提示。沒有 R 行的單元照舊只有句子。`tools/check_bank.py` 已接受 R 行。
