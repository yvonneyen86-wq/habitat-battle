## 各年級教材缺口

- **國一**：只有過去式（was/were、規則／不規則動詞）兩個單元有教材。Be 動詞、this/that、there is/are、現在簡單式（僅 L1 回顧）、現在進行式（僅 L1 回顧與測驗題）、can、Wh- 問句都沒有老師自己的教材。
- **國二**：涵蓋最完整（16 個單元）。because/although/but/so 沒有專屬單元（although…but 只出現在測驗翻譯題）；have to、How long 沒有教材。
- **國三**：現在完成式（3 個單元）與被動語態 (I) 有教材；被動 (II)、too…to／so…that、as…as／the more…、could／would／might／had better 只有計畫標題。關係子句、間接引述、if 條件句（僅測驗題）、分詞、make/let/have 使役動詞完全沒有教材。
- 年級判定不確定的單元：L16（as…as 單獨看是國二，the more…the more 是國三，依「進階」標題歸國三）、L17（could/would/might/had better 跨八下–九上，依「進階」標題歸國三）、L10／L11（反身代名詞、不定代名詞、附加問句不在指定清單中，依課本常見冊別歸國二）。
